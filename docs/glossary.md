# Glossary

- **ADR — Architectural Decision Record:** Stable, reviewable record of a design choice, alternatives, rationale, consequences, and provenance.
- **CI — Continuous Integration:** Automated checks on changes; a passing check does not replace independent architectural review.
- **PR — Pull Request:** Proposed set of Git changes for review and merge.
- **Gate 1:** Mandatory independent hostile review before any executable Lean implementation; all findings require documented closure.
- **Gate 2:** Mandatory independent review after the first reference implementation, per recovered ADR-046.
- **Lean 4:** The proposed formal proof language, not yet authorized for executable implementation.
- **mathlib:** Lean mathematical library that must be pinned and evaluated after Gate 1.
- **Verification:** Evidence that a specified property holds under its assumptions; not evidence of biological validity.
- **Recovery status:** Whether a claim is verbatim verified, a partial historical summary, a current proposal, or not recovered.
