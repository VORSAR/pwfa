# Problem statement

PWFA investigates whether a spatially distributed, nonlocally coupled phase system can support persistent internal memory and interaction with external knowledge.

The recovered account includes encoding, storage, retrieval, observation, learned pairwise coupling, and reinjection. **The full original system description and governing equations have not been recovered.**

This is a research question, not a demonstration of intelligence, biological fidelity, or performance advantages. Formal correctness can establish properties of a chosen model under assumptions, not correspondence to cognition.
