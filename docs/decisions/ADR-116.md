# ADR-116 — Anchor recall to the phase at the torus origin

Accepted on 2026-11-24. The owner selected option A in the decoder architecture discussion. The historical source records “anchor 0” and an anchored signed-imaginary decoder at $t=40$. This decision specifies how the first two-dimensional recall experiment interprets that anchor. [Historical encoder and decoder](ADR-095.md) · [16-bit input geometry](ADR-115.md)

## Decision

At the recall time $t$, take the reference phase $a(t)=z((0,0),t)$ from the evolving field. Given a bit observation $u_j(t)$ in the same phase coordinates, use the signed imaginary component $s_j(t)=\operatorname{Im}(\overline{a(t)}\,u_j(t))$ as the relative-phase signal. The observation operator producing $u_j$, the assignment of sign to bit value, the decision threshold, and the ambiguity rule need separate specifications. The origin is distinct from all sixteen input centers.

## Alternatives discussed

- **A. Use the instantaneous phase at the spatial origin.** The assistant recommended this and the owner selected it. For a unit-phase field the reference is always defined. A local perturbation at the origin can influence all bit readings.
- **B. Use a prescribed external phase of zero.** This is simple to evaluate and introduces a dependence on the synchronization of clock and phase.
- **C. Use the phase of the spatial mean.** This can reduce dependence on a single location. A winding field can have zero mean, so this option would require an additional failure rule.

## Validation implications

Under a common unit rotation $c$, the relative observation obeys $\overline{ca}\,(cu)=\overline a\,u$. A decoder test should rotate the entire field and confirm the same scores when the observation operator transforms by that rotation. Test localized anchor disturbances separately. The numerical contract must specify how to evaluate the field at the physical origin for the selected grid placement.
