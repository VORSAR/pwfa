# ADR policy

Architecture decisions are in individual files with stable `ADR-XXX.md` identifiers. Numeric suffixes identify decisions, **not document versions**. Find existing entries in [the index](index.md).

## Required fields

Status; decision date (or unknown); provenance; original A/B/C/Other alternatives where recovered; exact selected option; assistant's contemporaneous recommendation (or NOT RECOVERED); rationale and tradeoffs; implications; affected contracts; proof obligations; research evidence with scope; links; chronology and amendment trail.

Historical unknowns remain **NOT RECOVERED**. Recovered choice letters without meanings must not become implementation requirements. Superseding an ADR requires a new ADR and bidirectional links. Correcting a mistaken transcription requires a dated, cited amendment.

Do not equate a recovered choice with a formally reviewed or experimentally validated outcome.
