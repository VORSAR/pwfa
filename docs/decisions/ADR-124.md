# ADR-124 — Equal episode weights in the first pairwise memory

Accepted on 2026-11-25. The owner selected A after reviewing the four-episode Lean check. The first memory design stores four words sequentially with dense signed pair observations. [Training input](ADR-123.md) · [Training order and carry](ADR-096.md) · [Fixed-summary checks](../research/recall-pilot-checks.md#weights-across-training-episodes)

## Decision

Give each completed training episode equal weight. For a given pair, let $s$ be its summary from the next completed episode and $M_n$ its mean over the first $n$ episodes. Write $M_{n+1}=(nM_n+s)/(n+1)$ and increment the completed-episode count once. The first value is the first summary. After four episodes the stored value is the arithmetic mean of all four summaries. Every new, independently trained library starts with zero completed episodes.

## Alternatives

- **A. Equal weight.** The owner selected the assistant's recommendation for a benchmark that tests all four stored words. Conflicting evidence can cancel.
- **B. Favor recent episodes.** A fixed retention parameter emphasizes later presentations. It is feasible, but changes the design objective and adds a parameter.
- **C. Run both as matched conditions.** This provides stronger empirical evidence about recency and costs another training and retrieval condition.

For the same four input summaries, reversing the order preserves their arithmetic mean. Training order can still change the summaries themselves when the phase dynamics depend on previously accumulated state. Retain the reverse-order ablation. This decision leaves the within-episode trace and its sampling window open. The global scalar gain uses its own state. [Memory contract](../mathematics/memory.md)
