# ADR-113 — Compare two coupling radii before selecting a default

Accepted on 2026-11-24. The owner selected option C for the first torus validation runs. The numerical radius is measured as a fraction of the unit spatial period. [Kernel family](ADR-111.md) · [Grid sizes](ADR-112.md)

## Decision

Run the primary smooth kernel and the same-radius disk comparator at $R=1/4$ and $R=3/8$ on each grid in ADR-112. Hold physical radius fixed while refining the grid. Include the radius-independent uniform control once per grid. This gives twelve finite-range configurations and three uniform controls before counting modes or time steps. Review wave-rate errors before choosing a default radius. Both radii remain candidates.

## Alternatives discussed

- **A. Start at $R=1/4$.** The assistant recommended this as a simple, more local starting point. On the 16×8 grid the open disk reaches one neighboring row on either side in the coarser direction.
- **B. Start at $R=3/8$.** This reaches two neighboring rows on each side at the same resolution. The support covers about 44 percent of the continuous torus area.
- **C. Compare both before naming a default.** The owner selected this paired study to obtain evidence for both radii. It doubles the number of finite-range configurations compared with choosing one radius.

## Evidence for the later choice

Record grid shape, physical radius, kernel, spatial mode, and error against its continuum rotation rate. Retain both axial errors on the rectangular grids. For the disk the independent reference is the one-dimensional chord integral. The smooth reference uses its own continuum coefficient and needs a reference evaluation accurate enough to resolve the reported error. Selecting the eventual default and defining numerical acceptance tolerances remain open.
