# ADR-102: Continuous two-dimensional periodic spatial domain

- **Status:** Accepted by owner; independent Gate 1 OPEN
- **Decision date:** 2026-11-22
- **Selected option:** B (Batch 2, Decision 2)
- **Provenance:** Explicit owner selection in PWFA conversation, 2026-11-22; NEW decision, not recovered historical wording.

## Context and original alternatives
- **A:** Continuous one-dimensional periodic ring, R/Z. Prior assistant recommendation for recovered 1D encoding and manageable verification.
- **B:** Continuous two-dimensional periodic torus, selected. Two periodic dimensions with higher modeling and computational costs.
- **C:** Finite one-dimensional periodic lattice as canonical model, simpler computation but discontinuous with original continuous research objective.
- **Other:** Not selected.

## Owner decision
Use the continuous spatial domain T² = (R/Z) × (R/Z), where coordinates are identified modulo one in both directions. This specifies topology, not an embedded doughnut geometry, metric, nonlocal kernel, sample grid or evolution law.

## Contemporaneous recommendation and tradeoffs
Assistant recommended **A**, ranked B second, and C third. The owner chose **B**. Advantages: spatial interactions can vary independently along two directions. Costs: increased spatial/grid and dense pairwise-memory complexity; prior 1D formulas cannot be silently generalized. The earlier qualitative ranks were not measured results.

## Proof and reconciliation obligations
1. Define measure, metric, periodic distance, function spaces, topology and regularity assumptions.
2. Reconcile historical [ADR-095](ADR-095.md) one-dimensional bump centers (j+1/2)/N and radius 0.4/N. No 2D encoding is yet selected.
3. Resolve whether N=128/256/512 represents per-axis resolution or total grid sites; record impacts on benchmark resource matching.
4. For S¹-valued fields on T², account for two independent winding indices, rather than treating historical winding 0/±1 as an already complete 2D specification.
5. Specify 2D quadrature, convergence, coupling, and observation with explicit evidence and proof obligations.
6. No executable Lean implementation before independent Gate-1 closure under ADR-046 and ADR-055.
