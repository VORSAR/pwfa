# ADR-108: Scope-limited independent Gate 1 for iterative vertical slices

- **Status:** Accepted by project owner; no slice has passed Gate 1
- **Decision date:** 2026-11-22
- **Selected option:** A (Decision 8)
- **Provenance:** Explicit owner selection in PWFA conversation on 2026-11-22. New governance decision, not a recovered historical recommendation.
- **Supersedes:** [ADR-055](ADR-055.md) **only as to the global scope of preimplementation closure**. Its rule that *all findings, including documentation findings, must close* remains fully in force for each slice.
- **Amends application of:** [ADR-046](ADR-046.md), retaining two independent hostile review gates per implemented slice: Gate 1 before that slice's executable implementation and Gate 2 after its first reference model.
- **Related:** [ADR-101](ADR-101.md), [preliminary hostile review](../verification/preliminary-hostile-review.md).

## Decision context and alternatives (presented 2026-11-22)

- **A — Independent Gate 1 per vertical slice (selected and recommended):** Freeze a bounded slice, obtain independent hostile review, resolve *every* finding within its declared scope, and only then allow that slice's executable Lean implementation. Keep integration/system findings and other slices open.
- **B — Preserve global Gate 1 unchanged:** No executable Lean until all PWFA contracts have been reviewed and all findings globally closed. Preserves the original integrated gate but delays incremental feedback.
- **C — Permit pre-review Lean sandbox:** Allow provisional executable investigations without independent closure. Enables quick experimentation but risks unreviewed assumptions entering reference implementations.
- **Other:** Not selected.

## Owner decision

**Option A.** Adopt a sequence of independently reviewed, scope-limited vertical slices, preserving full finding closure, traceability, and Gate 2.

This explicitly **supersedes the monolithic interpretation** of ADR-055 and narrows the Gate-1 timing in ADR-046. The old historical records must remain intact and independently traceable. The change does **not** allow pre-review executable Lean, and does **not** claim that a slice review constitutes whole-system Gate 1.

## Contemporaneous recommendation and tradeoffs

The assistant recommended A to allow mathematical feedback without waiting for the complete memory and oscillator architecture. Benefits: earlier formally checkable progress, bounded proof surfaces, and continuing external review. Costs: reviewers must enforce scope boundaries; integration findings cannot be waived; a component proof is not a system correctness or recall proof.

## Operational gate protocol

1. **Freeze scope:** Assign a stable slice ID, versioned Git commit SHA, normative definitions, explicitly excluded claims, dependencies and acceptance tests.
2. **Independent hostile review:** Reviewer independent of the slice's author and decision process, with recorded identity, scope, findings, severity, and independence declaration. A ChatGPT self-review or normal CI result is not independent.
3. **Close every finding:** Each finding, including minor documentation items, must link to remediation commits and independent closure attestations. No severity exemptions, no self-certification, no silent carry-forward.
4. **Authorize bounded implementation:** Only the exact reviewed contract, version and dependencies may be implemented in executable Lean, with pinned toolchains and reproducible CI. Review approval is not an assertion of empirical model behavior.
5. **Gate 2:** After the slice's first reference implementation, independently review the implementation and its conformance. Record all findings and disposition before describing that slice as fully verified.
6. **Change invalidation:** If normative assumptions, interfaces, theorem statements, or dependencies change, assess review impact and reopen affected slice approval. New broader claims require new reviews.
7. **Integration:** Before claiming a whole PWFA system works, a separate integration-level independent review must cover interactions, remaining original architectural obligations, and empirical validity. Passing individual slices does not close global findings.
