# ADR-115 — A 4×4 torus layout for 16-bit recall inputs

Accepted on 2026-11-24. The owner selected option A in the PWFA architecture discussion. This decision locates the sixteen input bits for the first recall experiment on the two-dimensional periodic domain. The historical ring retains its one-dimensional reference. [Historical encoder](ADR-095.md) · [Torus domain](ADR-102.md) · [Recall benchmark](ADR-099.md)

## Decision

Divide each period into four equal intervals. Place one bit at the center of each of the sixteen square cells. The centers are $((2i+1)/8,(2j+1)/8)$ modulo one, for $i,j$ from zero through three. These are physical positions on the unit torus and stay fixed when solver resolution changes. They describe sixteen input sites, while the solver grid counts all spatial samples. [Grid decision](ADR-112.md)

## Alternatives discussed

- **A. Use a 4×4 torus layout.** The assistant recommended this and the owner selected it. The centers use both coordinates and the position set is symmetric under exchange of the axes. The stimulus shape and decoder still require calibration.
- **B. Establish the historical ring benchmark first.** This keeps the recovered one-dimensional placement and defers the two-dimensional recall experiment.
- **C. Encode the bits on sixteen periodic stripes.** This gives a direct one-axis stimulus on the torus and leaves the pattern constant in the other direction.

## Consequences and checks

The cells tile the period and their centers are distinct modulo one. The next encoder contract must assign bit indices to centers, define how bit values and cues set the phase stimulus, specify support and normalization, and define how the anchor yields a decoded bit or an ambiguous result. A 32-bit sensitivity experiment needs a separate placement choice. The structural coupling radii in ADR-113 describe oscillator interaction; the encoder bump width has its own physical meaning and is still open.
