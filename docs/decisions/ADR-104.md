# ADR-104: Isotropic distance-based periodic coupling geometry

- **Status:** Accepted by owner; kernel equation and Gate 1 review OPEN
- **Decision date:** 2026-11-22
- **Selected option:** A (Batch 3, Decision 4)
- **Provenance:** Explicit project-owner selection in the PWFA conversation on 2026-11-22; NEW decision, not recovered historical wording.
- **Related:** [ADR-101](ADR-101.md), [ADR-102](ADR-102.md), [ADR-103](ADR-103.md), [ADR-105](ADR-105.md), [ADR-093](ADR-093.md)

## Context and original alternatives

- **A — Isotropic periodic distance-based baseline:** base interaction strength depends only on periodic distance, without an explicit directional preference. **Selected; contemporaneous assistant recommendation.**
- **B — Anisotropic periodic baseline:** base coupling may weight spatial directions differently, permitting directional preference but introducing parameters.
- **C — Arbitrary learned coupling geometry:** pairwise interaction geometry is freely adaptive, increasing expressive capacity and verification complexity.
- **Other:** Not selected.

## Owner decision

Select a **distance-based isotropic baseline kernel**, provisionally expressible as K0(x,y)=k(d(x,y)) for points x,y on T², with distance d defined in [ADR-105](ADR-105.md).

**Interpretation limit:** This decision does not imply invariance under arbitrary global rotations of the square flat torus; global isometries are restricted by its periodic lattice. It constrains the **base spatial kernel**, not the full learned effective coupling. The learned pairwise memory term of [ADR-093](ADR-093.md) may be spatially heterogeneous. The kernel profile k, its signs, normalization and evolution operator remain undecided.

## Contemporaneous recommendation, pros and cons

The assistant recommended A, ranked B second and C third. Pros: radial baseline, fewer directional parameters, compatible with the continuous periodic model, simpler null comparisons. Cons: cannot directly model intrinsic directional preference in the baseline; isotropic distance does not guarantee stable or accurate memory recall. B permits directional preferences but adds parameters; C allows greater flexibility but may confound geometry with learning. Rankings were qualitative, not empirical.

## Obligations and traceability

1. Choose a kernel profile, normalization, support and assumptions separately, with a new owner decision.
2. State exact periodic-distance behavior at cut loci (multiple shortest representatives), including regularity requirements.
3. Separate radial baseline geometry from learned spatially varying pairwise memory; preserve [ADR-093](ADR-093.md).
4. Establish integration, equivariance under actual torus symmetries, existence, convergence and sensitivity claims only with justified assumptions.
5. Maintain [Gate 1](../verification/review-gates.md) blocking on executable Lean implementation.
