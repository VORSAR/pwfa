# ADR-120 — Background phases for the first encoder validation

Accepted on 2026-11-24. The owner selected option A for the phase field immediately before presenting a validation cue. [Omitted masked stimulus](ADR-119.md) · [Bit phases](ADR-118.md)

## Decision

In the primary condition, initialize every point to the same unit phase. This includes the origin and all sixteen input sites. In the sensitivity condition, repeat the comparison with a reproducible spatially varying unit-phase field generated independently of the target word. Record enough information to reproduce each initialization, including the seed when using a seeded generator. Use the same realized background and corrupted cue when comparing phase maps within a condition.

## Alternatives and evidence

- **A. Uniform primary background plus a varied sensitivity check.** The assistant recommended this option and the owner selected it. It gives a known initial signed score and measures how much the results depend on that preparation.
- **B. Uniform background alone.** This gives the same clean reference with fewer runs and leaves robustness to pre-existing local phases open.
- **C. Varied background as primary.** This exercises background dependence immediately and makes attribution of errors to cue omission more difficult.

For an omitted point on a uniform background with unit phase $a$, its score before subsequent evolution is the imaginary part of $\overline a a=1$, hence zero. On a nonuniform background it can be nonzero. The check concerns the point score before any other stimulation or dynamics affects the site. Spatially pooled readout, recall scores at $t=40$, and training reset or carry behavior have separate contracts. ## Open specification

The spatial field generator and its variation scale and strength still need to be specified. A single reproducible field can validate execution; conclusions about robustness depend on the selection of backgrounds and cues in the evaluation protocol.
