# ADR-133 — Matched comparator for the recall criterion

Accepted on 2026-11-28. The owner selected option 1. The figures behind the options were reproduced in Lean on both development libraries before this record was written. [Mission criterion](ADR-100.md) · [Static references](../research/learned-retrieval-at-time-zero.md#static-references-on-the-two-development-libraries) · [Lean rule](ADR-131.md)

## Decision

Measure the ADR-100 advantage against a classical Hopfield associative memory that works from the same stored pair summary as PWFA. Its weights are the signed agreements between bit positions under the same episode weights, with zero self-coupling. That matrix is the PWFA learned memory restricted to the sixteen bit centers at the primary alphabet. Report nearest-stored-word lookup on the visible positions beside every comparison. Lookup reads the raw stored words, so it stands outside the matched comparison as a reference.

The comparator's equal-resource budget, update schedule and tie handling remain to be specified before the held-out benchmark, together with the aggregation across libraries and the statistical protocol. The evidence below uses asynchronous sign updates in index order until nothing changes. That schedule is a reference and has no standing as the final one.

## Alternatives and evidence

The figures are exact-word rates over the 43,680 corruptions with two flips and two omissions of each development library.

- **1. Classic memory network, with lookup shown beside it.** The assistant recommended this option and the owner selected it. Both sides start from the same stored information. The network recovers 62.05% and 76.54% with equal weights. A time-zero estimate of the current PWFA hidden-bit readout gives 57.90% and 63.02%. That estimate is a prediction from a formula, so PWFA's measured standing against this comparator is still open.
- **2. Nearest-word lookup alone.** This is the simplest and hardest yardstick. It recovers 96.06% and 99.18%, which leaves at most 3.94 and 0.82 points for any decoder. A five-point advantage is impossible on these libraries under this corruption rule.
- **3. Decide later.** This avoids committing before a single-run method works. Choosing the yardstick after seeing results would weaken any later claim.

The time-zero estimate agrees with archived oscillator output on 1,244 of 1,280 symbols and on 41 of 64 corrupted whole words. [Lean executable](../../scripts/experiments/pair-memory-reference.lean) · [Lean identities](../../scripts/experiments/presented-bit-torque.lean)

## Consequences

The matched-comparison item on the roadmap keeps its open parts: budget, schedule and preregistration. From here on, development results show the Hopfield and lookup references on the same cues.
