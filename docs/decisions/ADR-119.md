# ADR-119 — Omit bit-specific stimulation for masked cues

Accepted on 2026-11-24. The owner selected option 2A after reviewing the Lean cue-preparation example. [Bit-phase map](ADR-118.md) · [Masked recall benchmark](../experiments/benchmarks.md)

## Decision

A masked input contributes no bit-specific stimulus at its location. The encoder receives the mask and the unmasked cue values; the held-out target bit is available to the evaluator for scoring at recall. Record how the background phase was initialized, since it can already carry a nonzero signed signal before stimulation. The local unit phase participates in the ordinary field dynamics throughout recall. [Encoding contract](../mathematics/encoding-decoding.md)

## Alternatives and evidence

- **2A. Omit the bit-specific stimulus.** The assistant recommended this option and the owner selected it. It directly tests recovery of missing information and is simple to implement with an availability flag.
- **2B. Write the instantaneous anchor phase.** This produces zero immediate signed point score and can overwrite an existing local phase.
- **2C. Write a seeded random phase.** This provides a reproducible distractor with a potentially strong signed signal.

For the cue-preparation model that retains the current phase when a write is absent, omission and an anchor write yield the same state exactly when the background phase equals the anchor. With anchor 1 and background i, omission gives a score of +1 and an anchor write gives 0. The initial background, duration of any stimulus, and thresholds still need their own specifications.
