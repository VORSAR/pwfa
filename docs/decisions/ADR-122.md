# ADR-122 — Primary denominator for exact-word recall

Accepted on 2026-11-25. The owner selected A in the recall-scoring decision after the synthetic Lean comparison. This applies to the primary $t=40$ endpoint. [Benchmark](../experiments/benchmarks.md) · [Scoring check](../research/recall-pilot-checks.md#counting-exact-words)

## Decision

For each evaluation condition, let $N$ be the number of scheduled cues, $C$ the number that return a complete decoded word, and $E$ the number that match all sixteen target bits. Report the counts and the primary rate $E/N$. An abstention or a failed retrieval contributes one scheduled cue and zero exact matches. Report coverage $C/N$ and answered-only accuracy $E/C$ alongside it. A zero denominator gives an undefined rate. Retain the identities of scheduled cues so a missing result cannot silently drop from the denominator.

## Alternatives

- **A. All scheduled cues primary.** The owner accepted the assistant's recommendation. This measures the chance that the system actually returns the complete correct word on a scheduled cue.
- **B. Answered-only primary.** This measures correctness conditional on returning a word. Changes in abstention or failure rates could raise that percentage even when fewer scheduled cues yield the correct word.

The decoder confidence threshold, cue generation, and statistical aggregation across libraries remain open. The decision fixes the counting rule within each reported set of scheduled cues. [Requirements](../verification/requirements-matrix.md)
